# Hidden overweight and adverse birth outcomes among Asian mothers in the United States, 2016–2023

Analytic code for:

> Tasnim Jahan J, Afrose S. Hidden overweight and adverse birth outcomes among Asian mothers in the United States, 2016–2023: a population-based repeated cross-sectional study. Submitted to *Paediatric and Perinatal Epidemiology*, 2026.

**Manuscript status:** Under review at *Paediatric and Perinatal Epidemiology* (submitted 2 November 2026). This repository accompanies the submitted manuscript. Findings and scripts may be updated following peer review.

## Data

This study uses the National Center for Health Statistics (NCHS) National Vital Statistics System (NVSS) Natality Public-Use Files, 2016–2023. The data are public and de-identified and are **not** included in this repository.

Download the files from: https://www.cdc.gov/nchs/data_access/vitalstatsonline.htm

Variable definitions follow the NCHS *User Guide to the Natality Public Use File* for each year.

## How to run

1. Download the NVSS natality files for 2016–2023.
2. Set the paths at the top of each SAS script:
   ```sas
   %let RAWDIR = /path/to/nvss/files;   /* 01_data_prep.sas only */
   libname ana "/path/to/your/data";
   %let OUTDIR = /path/to/your/output;
   ```
   In `01_data_prep.sas`, check that the eight file names (`f2016` to `f2023`) match the files you downloaded.
3. Run the scripts in order:

| Script | Purpose | Produces |
|---|---|---|
| `sas/01_data_prep.sas` | Reads the 2016–2023 fixed-width files, pools them, applies the Figure 1 exclusions, derives variables, builds `ana.analytic_pooled` and the Asian + White analysis file `ana.wa`, compares excluded and included records | Figure 1 counts, Table 1, eTable 2 |
| `sas/02_main_models.sas` | Asian vs White risk ratios; modified Poisson models (log link, sandwich variance), standardized risks, subgroup and spline analyses | Table 2, Table 3, Table 4, Figure 2, eTables 1, 3A, 4, 5B, eFigures 2 and 3 data |
| `sas/03_sensitivity.sas` | Missing marital status (missing indicator, omitted, multiple imputation), eclampsia excluded, 2022–2023 only, spline robustness, E-values | eTable 3B, eTable 5A, eTable 6 |
| `r/figures.R` | Plots from the SAS output (including `efig2_spline_grid.csv`) | Figure 2, eFigures 2 and 3 |

`02_main_models.sas` and `03_sensitivity.sas` write RTF results files to `OUTDIR`; `01_data_prep.sas` prints its checks and tables to the SAS output window. Then set `out_dir` near the top of `r/figures.R` to the same results directory, and run the R script. `r/figures.R` requires `efig2_spline_grid.csv` generated by `02_main_models.sas`.

**Reproducibility note:** Some values for Figure 2 and eFigure 3 are manually transcribed from manuscript tables/SAS summaries in `r/figures.R`, and the E-value inputs in `03_sensitivity.sas` are hard-coded from Table 3. If model estimates change, manually update and verify these values. No raw NVSS files or model results are supplied here.

**Figures drawn by hand:** Figure 1 (flow diagram) and eFigure 1 (directed acyclic graph) were drawn in Microsoft PowerPoint. The Figure 1 counts come from `01_data_prep.sas`, Part A. The eFigure 1 nodes are the exposure, outcomes and covariates listed under Key analytic choices below.

## Key analytic choices

- **Population:** singleton live births to single-race non-Hispanic Asian mothers (primary) and non-Hispanic White mothers (comparison), BMI 13.0–69.9 kg/m².
- **Exposure:** prepregnancy BMI in five Asian-specific categories based on the WHO action points (23.0 and 27.5 kg/m²): <18.5, 18.5–22.9 (reference), 23.0–24.9, 25.0–27.4, ≥27.5.
- **Outcomes:** hypertensive disorders of pregnancy, caesarean delivery, preterm birth (<37 weeks), low birthweight (<2500 g).
- **Covariates:** maternal age, education, marital status, live birth order, prenatal care timing, payment source, infant sex, smoking, nativity, birth year, and detailed Asian subgroup (Asian-only models).
- **Multiple imputation:** FCS logistic for marital status, 50 imputations, seed 20260616.
